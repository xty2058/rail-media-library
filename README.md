# 镜头库

智能素材库的 macOS 本地版。首页提供三个入口。

- **导入已有素材**。批量上传图片和视频，自动生成描述、标签和预览，记录素材来源。审核通过后可在正式库按标签和地点浏览。
- **按脚本找镜头**。从正式素材库按脚本和条件筛选，查看推荐依据、排除原因和剩余缺口。
- **网上找素材**。从 Wikimedia Commons 搜索。视频缺口可补查 Internet Archive，也可手动提交来源链接。候选进入原有审核队列，授权和对外发布用途由审核人确认。

## 本地启动

需要 macOS、Python 3.9 或更新版本，以及 Xcode 命令行工具。解压后，在终端进入本文件夹并运行：

```sh
./start.sh
```

浏览器打开 [本地素材库](http://127.0.0.1:8765/)。首次运行会编译本地媒体助手，并在项目下建立空的 `data/` 目录。若端口占用，可运行 `./start.sh --port 8766`，然后访问对应端口。

### WebM 预览

项目会使用系统中的 FFmpeg。也可以在项目目录安装项目内的版本：

```sh
python3 -m pip install --only-binary=:all: --target data/build/video-tools imageio-ffmpeg==0.6.0
```

自动下载上限为图片 12 MB、视频 50 MB。下载的 WebM 原件保留，后台生成 MP4 供预览和媒体分析。

### 搜索 Agent

固定搜索可以直接使用。要启用 Agent，复制配置模板：

```sh
cp search-agent.example.json search-agent.local.json
chmod 600 search-agent.local.json
```

在本机配置文件填写服务商、模型、接口根地址和 API Key。然后在「网上找素材 → 搜索设置」选择 Agent 搜索。上传到 GitHub 时保留示例配置即可。

## 快速验收

1. 用自己有权使用的一张图片和一段短视频批量导入，查看描述、标签和来源。用合法的授权凭据完成审核后，检查正式素材库分类。
2. 搜索与已审核素材相关的脚本，检查推荐理由。再加一个素材达不到的时长或画面条件，查看排除原因和缺口。
3. 从缺口进入「网上找素材」，检查条件带入和「仅视频」选项。查看 Commons 结果与补充来源，也可手动提交一个网页链接，再打开「审核本次候选」。

本地版使用 macOS 的 Swift 和 Apple Vision。小组共用网页使用仓库的 Docker 配置，部署步骤见 [小组部署说明](DEPLOY.md)。
